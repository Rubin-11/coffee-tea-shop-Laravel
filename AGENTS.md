# AGENTS.md — Coffee-Tea Shop

> Карта проекта для людей и агентов. Это **оглавление**, а не энциклопедия: короткий файл-указатель. Подробности — в `docs/`, актуальный код — источник истины.

## Что это за проект

**Coffee-Tea Shop** — интернет-магазин премиального кофе, чая и сопутствующих товаров. Laravel-приложение в Docker-окружении. Общение и документация — **на русском**.

## Стек

- **Laravel 12** (PHP 8.2+) — код приложения в `src/`
- **PostgreSQL 18** — база данных
- **Docker + docker-compose** — окружение (nginx, php, postgres)
- **Makefile** — все команды (`make help` — список)
- **Blade** — шаблоны, **Vite** — сборка фронтенда

## Быстрый старт

```shell
make up          # запустить контейнеры
make migrate     # выполнить миграции
make fresh       # пересоздать БД с сидами
make test        # запустить тесты
make shell       # войти в PHP-контейнер
make db          # консоль PostgreSQL
```

> ⚠️ **Важно про Makefile:** при передаче флагов artisan добавляй ` -- ` перед ними:
> `make controller TestController -- --invokable` (см. шапку Makefile).

## Правила для агентов

1. **Не писать код вручную за человека без задачи** — ждать явной инструкции. Человек управляет, агент выполняет.
2. **Перед коммитом запускать `make test`** — тесты должны проходить.
3. **Коммиты — в стиле Conventional Commits** (уже принят в проекте): `feat:`, `fix:`, `docs:`, `test:`, `chore:`, `refactor:` — описание на русском.
4. **Все изменения БД — только миграциями** (`make migrate`), не редактировать схему руками.
5. **Не трогать `src/vendor/`** и сгенерированные файлы — они в .gitignore.
6. **Логика — в сервисах (`app/Services/`), контроллеры — тонкие.** Следовать принятой архитектуре из `docs/ARCHITECTURE.md`.
7. **Не ломать существующее:** при изменении поведения обновлять тесты и документацию.
8. **Спрашивать при неопределённости** — лучше уточнить, чем сделать не то.

## Рабочий процесс

1. Задача → короткий план (что меняем, где, какие тесты) → согласование с человеком
2. Внесение изменений → `make test` → коммит (conventional)
3. Отчёт человеку: что сделано, что изменилось, что проверить
